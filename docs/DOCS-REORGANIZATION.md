所有文件都可以從 README.md 的「文件導覽」章節進入：

```markdown

本專案提供多份主題文件，方便快速找到所需資訊：

> 📖 **完整文件索引**：請參閱 DOCS-INDEX.md，取得詳細導覽和閱讀建議

| 文件                      | 說明           | 適合對象     |
| ------------------------- | -------------- | ------------ |
| README.md                 | ...            | 所有使用者   |
| DOCS-INDEX.md             | 文件索引與導覽 | 所有使用者   |
| CONFIG-GUIDE.md           | ...            | 部署與維護者 |
| SECURITY.md               | ...            | 系統管理員   |
| RSS-FIX-GUIDE.md          | ...            | Podcast 開發者   |
| CHANGELOG-新聞來源擴充.md | ...            | 開發者       |
```

### 文件內部導覽

每份主題文件都包含：

- 回到主要文件的連結

- 內部章節跳轉

```markdown
> 📖 **文件導覽**：[← 回到 README](./README.md) | [安全指南](./SECURITY.md) | [RSS 修復指南](./RSS-FIX-GUIDE.md)
```

## 📝 維護指南

### 新增文件時

1. 建立新的 Markdown 文件
2. 在文件開頭新增導覽：
   ```markdown
   > 📖 **文件導覽**：[← 回到 README](./README.md) | [其他文件](./OTHER.md)
   ```
3. 更新 README.md 的文件導覽表格
4. 更新 DOCS-INDEX.md，新增文件說明
5. 在相關文件中新增交叉引用

### 更新現有文件時

1. 確保導航連結正確
2. 更新 DOCS-INDEX.md 中的說明（如果內容有重大變更）
3. 檢查其他文件的交叉引用是否需要更新
